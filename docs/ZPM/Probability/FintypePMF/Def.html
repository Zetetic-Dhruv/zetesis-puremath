    ProbabilityTheory.FintypePMF

    FintypePMF: an ℝ-valued, Fintype-indexed probability mass function #

    ProbabilityTheory.FintypePMF α is a probability mass function over a finite type α, with ℝ-valued weights and the summation axiom phrased via Finset.sum. It coexists with Mathlib.PMF α rather than duplicates it: the ℝ-valued / Finset.sum-based encoding is what lets linarith / nlinarith / field_simp compose in arithmetic-heavy proofs (for example the multiplicative-weights-update analysis), where the ℝ≥0∞-valued Mathlib PMF would require toReal round-trips at every step.

    The precedent for this coexistence is documented in the repository CHARTER.md under "Duplicate rule exception: proof-engineering specializations."
